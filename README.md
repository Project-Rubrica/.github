# Rubrica organization profile

Public profile content for the Project-Rubrica GitHub organization.

Edit profile/README.md to update the organization landing page. Brand assets come from the supplied rubrica-logo-export package. This repository contains public-facing profile materials only.

## Service architecture planning

The [cross-service architecture, repository catalog and implementation roadmap](https://github.com/Project-Rubrica/rubrica-docs) describe the proposed polyglot platform. Shared [OpenAPI/event contracts and local Swagger](https://github.com/Project-Rubrica/rubrica-spec) are planning artifacts. Implementation languages remain open. This documentation update adds no runtime functionality and authorizes no backend implementation or deployment.

This repository remains the organization profile/branding home. Brand assets are shared references, not an application service. Follow the existing approved asset records in rubrica-landing.
